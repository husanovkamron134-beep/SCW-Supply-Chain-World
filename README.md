# Supply Chain World (SCW)

SCW is a browser-first supply chain and warehouse learning platform.

## Phase 1
- Interactive warehouse dashboard
- Inventory receiving and dispatch simulation
- Warehouse visualization
- Academy lessons and logistics formulas
- Reorder point (ROP) calculator and what-if simulation

## Run
Open `index.html` in a modern browser. An internet connection is required for the 3D and font CDN resources.

## Project status
Phase 1 prototype. Data is stored locally in the browser; there is no shared backend yet.
